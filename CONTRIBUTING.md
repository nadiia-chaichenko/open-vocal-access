# Contributing to Open Vocal Access

Thanks for considering a contribution to this early-stage project.

## Ways to contribute

- Correct factual repertoire metadata with a reliable source.
- Propose clearly licensed additions to the CSV catalogue.
- Improve documentation, testing, usability, and accessibility.
- Report a bug with clear steps to reproduce it.

Please propose substantial changes in an issue before writing them. Voice types are descriptive conventions rather than definitive casting recommendations; note disputed classifications rather than silently overwriting them.

## Local validation

1. Use Python 3.10 or newer.
2. Run `python3 -m unittest discover -s tests -v`.
3. Run `python3 vocal_access.py --language Italian` to check catalogue integrity.
4. Explain changes in a pull request.

Do not commit personal information, credentials, copyrighted scores, copyrighted recordings, or other material without redistribution rights.

Contributors retain rights to their work and agree to make contributions available under the project's MIT License.
